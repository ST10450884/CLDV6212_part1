# CoffeeNChill – CLDV6212 Part 1

## Project Overview

CoffeeNChill is a serverless Azure Functions application developed for CLDV6212 Part 1.

The application demonstrates the use of:

- Azure Functions using .NET 10 Isolated
- Azure Table Storage for menu item management
- Azure Blob Storage for staff document management
- Azurite for local Azure Storage emulation
- Docker for containerisation
- Postman for API testing
- GitHub for source control
- Docker Hub for container image hosting

The solution provides HTTP-triggered Azure Functions that perform CRUD operations on menu items and allow staff documents to be uploaded, listed, and downloaded.
